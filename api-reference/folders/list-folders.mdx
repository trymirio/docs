---
title: "List folders"
api: "GET /folders"
description: "List your organization's folders"
---

Returns all folders in your organization.

### Response

An array of `{ id, name, created_at, retention_policy_days }`. `retention_policy_days` is `null` when the folder has no [retention policy](/platform/folders-and-permissions#transcript-retention).

<RequestExample>
```bash cURL
curl https://api.getversive.com/api/v1/folders \
  -H "Authorization: Bearer $VERSIVE_API_KEY"
```
</RequestExample>
