---
title: "Update folder"
api: "PATCH /folders/{id}"
description: "Rename a folder or set its retention policy"
---

Updates only the fields you send.

<ParamField path="id" type="string" required>
  The folder ID.
</ParamField>

<ParamField body="name" type="string">New folder name.</ParamField>
<ParamField body="retention_policy_days" type="integer | null">
  Days to keep interview transcripts and recordings in this folder's studies, from 1 to 36500, counted from each interview's last message. Send `null` to turn retention off. Setting it on a folder with existing studies deletes their transcripts and recordings older than the window at the next hourly check. See [Interview data retention](/platform/folders-and-permissions#interview-data-retention) for what is deleted and kept.

  Organization API keys can change this field. Over an MCP connection, only the organization owner can.
</ParamField>

### Response

<ResponseField name="id" type="string" />
<ResponseField name="name" type="string" />
<ResponseField name="created_at" type="string" />
<ResponseField name="retention_policy_days" type="integer | null" />

<RequestExample>
```bash cURL
curl -X PATCH https://api.getversive.com/api/v1/folders/5c1d2e3f-4a5b-4c6d-8e7f-9a0b1c2d3e4f \
  -H "Authorization: Bearer $VERSIVE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "retention_policy_days": 30 }'
```
</RequestExample>
