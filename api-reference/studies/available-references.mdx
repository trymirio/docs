---
title: "List available references"
api: "GET /studies/{study_id}/available-references"
description: "Which earlier questions can be referenced from a given position"
---

Returns the catalog of questions that can be [referenced](/api-reference/questions/batch-questions#question-references-mentions) from a given position in the study — with ready-to-insert `{{Q:...}}` templates for each. Use this endpoint to build an "@-mention" picker or discover the exact token for one option response.

Always copy the returned `template` into the destination question's `content`. A full-answer token such as `{{Q:<question_id>}}` inserts the complete response. To insert one item from a structured answer, choose an entry whose `kind` is `property`.

<ParamField path="study_id" type="string" required>
  The study ID.
</ParamField>
<ParamField query="before_question_id" type="string">
  Only return questions that appear **before** this question — use when editing an existing question.
</ParamField>
<ParamField query="before_display_order" type="integer">
  Only return questions with a lower display order — use when composing a new question. Ignored if `before_question_id` is set.
</ParamField>

## Supported question types

The following source question types can be mentioned:

- `textInput`, `shortText`, and `multipleChoice` — full answer only.
- `matrixRatingScale` — full answer or `ratingForItem[index]`, which returns the rating for one item.
- `ranking` — full answer, `rankOfOption[index]`, or `optionAtRank[index]`.
- `allocation` — full answer or `allocationForItem[index]`.
- `cardSort` — full answer, `categoryForCard[index]`, or `cardsInCategory[index]`.

Property indices are **zero-based**. For example, `ratingForItem[0]` selects the first entry in the matrix question's `props.options`.

<Callout icon="info-circle" color="#71717a">
  Property selectors are type-specific. There is no generic `.option[index]` selector, and multiple-choice questions expose only their full answer.
</Callout>

### Response

<ResponseField name="references" type="ReferenceableQuestion[]">
  Each entry has `question_id`, `display_order`, `type`, `content`, a human-readable `label`, and `available_references`.
</ResponseField>

<ResponseField name="available_references[].kind" type="string">
  `fullAnswer` for the complete response or `property` for one structured sub-answer.
</ResponseField>

<ResponseField name="available_references[].template" type="string">
  The exact `{{Q:...}}` token to insert into the destination question's `content`.
</ResponseField>

<ResponseField name="available_references[].property_name" type="string | null">
  Type-specific selector such as `ratingForItem`, `rankOfOption`, or `allocationForItem`. Null for a full answer.
</ResponseField>

<ResponseField name="available_references[].property_index" type="integer | null">
  Zero-based option, category, or rank-position index. Null for a full answer.
</ResponseField>

<ResponseField name="available_references[].option" type="string | null">
  Human-readable option, category, or rank position selected by the property reference.
</ResponseField>
