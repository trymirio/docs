---
title: "Get study metrics"
api: "GET /studies/{id}/metrics"
description: "Response counts and quota progress for a study"
---

Returns response counts and quota progress for a study. Counts exclude archived, mock, and AI-simulated interviews.

<ParamField path="id" type="string" required>
  The study ID.
</ParamField>

### Response

<ResponseField name="complete" type="integer">Completed interviews.</ResponseField>
<ResponseField name="in_progress" type="integer">Interviews a participant has started but not finished.</ResponseField>
<ResponseField name="screened_out" type="integer">Participants screened out by logic rules or question quotas.</ResponseField>
<ResponseField name="quota" type="integer | null">
  The total-completes cap when the study uses one, otherwise `null`. Kept for compatibility; use `quotas` for the full picture.
</ResponseField>
<ResponseField name="quotas" type="object">
  Quota configuration and progress, same shape as [Get quota progress](/api-reference/quotas/get-quota-progress).
  <Expandable title="properties">
    <ResponseField name="mode" type="string">`off`, `fixed` (total completes), or `url_param` (per link parameter).</ResponseField>
    <ResponseField name="fixed" type="object | null">`{ limit, complete }` in `fixed` mode.</ResponseField>
    <ResponseField name="param_name" type="string | null">The URL parameter in `url_param` mode.</ResponseField>
    <ResponseField name="buckets" type="array">One `{ value, limit, complete }` per link value in `url_param` mode.</ResponseField>
    <ResponseField name="unmatched_param_policy" type="string">`allow` or `reject`: what happens to participants whose link has no matching value.</ResponseField>
    <ResponseField name="question_buckets" type="array">
      One `{ question_id, kind, match, value, limit, complete }` per [question quota](/studies/question-quotas), regardless of `mode`.
    </ResponseField>
  </Expandable>
</ResponseField>
<ResponseField name="status" type="string">The study status (e.g. `published`, `paused`).</ResponseField>

Derive "quota met" or "spots remaining" from `limit` and `complete` yourself. A `limit` of 0 means the bucket is closed.

<RequestExample>
```bash cURL
curl https://api.getversive.com/api/v1/studies/9b2f7c1e-4a4b-4f6e-9a1d-1c2d3e4f5a6b/metrics \
  -H "Authorization: Bearer $VERSIVE_API_KEY"
```
</RequestExample>
