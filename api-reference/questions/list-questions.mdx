---
title: "List questions"
api: "GET /questions"
description: "List a study's questions with logic and mentions"
---

Returns all questions in a study in the order the study editor shows them (Q1, Q2, ...), each with its logic rules and resolved mentions. A group's questions come together where the group sits, and every Randomizer arm is included in arm order.

<ParamField query="study_id" type="string" required>
  The study whose questions to list.
</ParamField>

### Response

An array of question objects:

<ResponseField name="id" type="string">Question ID.</ResponseField>
<ResponseField name="content" type="string">The question text (may include `{{Q:...}}` reference placeholders).</ResponseField>
<ResponseField name="type" type="string">
  Question type — e.g. `question` (AI Question), `textInput`, `shortText`, `message`, `email`, `multipleChoice`, `ratingScale`, `matrixRatingScale`, `matrixSelection`, `starRating`, `nps`, `number`, `dateInput`, `ranking`, `rankingWithMatrix`, `cardSort`, `allocation`, `allocationWithMatrix`, `conjoint`, `maxDiff`, `treeTest`, `prototypeTask`, `websiteTest`, `imageClick`, `externalLink`, `calendar`, `mediaUpload`, `exploratory`, `textHighlight`. Write endpoints accept only these values (case-sensitive); any other `type` is refused.
</ResponseField>
<ResponseField name="interviewer_notes" type="string | null">Private notes guiding the AI interviewer.</ResponseField>
<ResponseField name="display_condition_match" type="string">
  How the question's display conditions combine: `all` (every condition must be met) or `any` (one is enough).
</ResponseField>
<ResponseField name="display_order" type="integer">Position among the items that share its parent (its group, its Randomizer arm, or the top level). It restarts in every group and arm, so use the list order, not this field, for the question's place in the study.</ResponseField>
<ResponseField name="props" type="object">
  Type-specific settings (options, scales, limits, and so on). On an Image Choice question, each picture in
  `props.optionImages[].images[]` has the same `url`, `download_url` and `download_url_expires_at` fields as an asset.
</ResponseField>
<ResponseField name="assets" type="object[] | null">
  Attached media assets, default-language ones first in the order participants see them. Each has an `id`
  (`legacy-0`, `legacy-1`… for assets saved before ids; a language variant carries the `id` of the asset it
  replaces, plus its `language`), which `media` on [Update question](/api-reference/questions/update-question)
  keeps it by. Each asset keeps its stable `url` identifier and includes `download_url` for viewing
  or downloading it. Private storage links last one hour; `download_url_expires_at` is their UTC expiry time.
  Request this endpoint again for a fresh link. External URLs are passed through and have no expiry time.
  If a private file cannot be signed, both download fields are `null`; the rest of the response remains available.
  They are also `null` for private files when the organization turned off
  [uploaded file downloads](/platform/organizations-and-roles#uploaded-file-downloads).
</ResponseField>

Use `download_url` to fetch the file. When updating a question, retain the asset's `url` identifier and omit
the read-only `download_url` and `download_url_expires_at` fields. A private asset's identifier may contain
`/object/public/`; it identifies the stored file but cannot be used as a public download link.

<ResponseField name="logic" type="object[]">
  The question's logic rules — same shape as [question logic](/api-reference/question-logic/list-question-logic).
</ResponseField>
<ResponseField name="mentions" type="object[]">
  Resolved `{{Q:...}}` references in the content: `placeholder`, `referenced_question_id`, `label`, `type` (`question` | `propertyAnswer`), `property_name`, `property_index`, `valid`, `error`.
</ResponseField>

<RequestExample>
```bash cURL
curl "https://api.getversive.com/api/v1/questions?study_id=9b2f7c1e-4a4b-4f6e-9a1d-1c2d3e4f5a6b" \
  -H "Authorization: Bearer $VERSIVE_API_KEY"
```
</RequestExample>
