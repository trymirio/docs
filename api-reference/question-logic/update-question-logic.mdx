---
title: "Update question logic"
api: "PUT /question-logic/{logic_id}"
description: "Modify a branching or display rule"
---

Updates a logic rule; only the fields you send change. Returns `204 No Content`.

<ParamField path="logic_id" type="string" required>The rule ID.</ParamField>

Body fields (all optional): `operation`, `comparison_value`, `comparison_value_type`, `next_question_id`, `next_question_group_id`, `redirect_url`, `end_interview`, `action_type`, `language`, `source_question_id` — same semantics and validation as [Create question logic](/api-reference/question-logic/create-question-logic), applied to the rule as it would be after the update.

On a display rule you can change the condition and `source_question_id`, never action fields. A rule's `logic_type` can't change: delete it and create a new one.

<RequestExample>
```bash cURL
curl -X PUT https://api.getversive.com/api/v1/question-logic/lr-42 \
  -H "Authorization: Bearer $VERSIVE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "comparison_value": "4" }'
```
</RequestExample>
