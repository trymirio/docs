AI tests let you test designs and websites with **AI personas** instead of recruited participants. Import a Figma prototype, paste a website URL, or upload design images, and get a detailed usability report — transcripts, screenshots, findings, and prioritized recommendations — in minutes.

## How a test comes together

1. **Create a project** from a Figma prototype, image upload, or website URL. Projects organize all the tests you run against one design.
2. **Configure the test** — the goal or task, the [test mode](/ai-tests/test-modes) (conversational, expert audit), the questions each screen is evaluated on, and optional extras like SUS questionnaires.
3. **Pick personas** — one or many, each with its own run count, from your [persona library](/ai-tests/personas) or written inline.
4. **Run it.** Each persona execution is one test run, and a single launch can include up to 50 runs across all selected personas. Runs complete in minutes; website tests can be watched live.
5. **Read the results** — per-run transcripts and screenshots, plus an aggregated summary with key takeaways and prioritized recommendations. See [Results & reports](/ai-tests/results).

## Projects & lifecycle

Projects live in folders alongside your studies and move through **Draft → Active → Completed / Archived** (a draft becomes active on its first run). You can duplicate a project to iterate on a new version of a design, and every run keeps a snapshot of the exact configuration and screens it tested — so old results stay meaningful as the design evolves.

Test runs themselves are **running → completed** (or *failed* — retryable once, free unless the retry succeeds; prototype runs can be *partially successful* if only some screens complete).

Credits are only charged for runs that **succeed** (including partially successful prototype runs) and come from the same allowance as study completions.
