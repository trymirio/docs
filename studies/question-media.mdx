Most questions can include rich media that participants see alongside (or instead of) the question text — the backbone of concept tests, design feedback, and stimulus-based research.

## Media types

| Type | Notes |
| --- | --- |
| **Images** | Screenshots, mockups, ad creative — anything visual. |
| **Figma prototypes** | Interactive embeds — participants click through the real prototype, with frame navigation. |
| **Videos** | With autoplay and loop options. |
| **PDFs** | Document display for concept docs, menus, one-pagers. |
| **Embedded websites** | Show a live site inside the question. |

## Layout & sizing

- **Layout** — inline with the question, or full-screen alongside it (best for detailed designs).
- **Sizing** — fit to view, or scroll for tall content.

## Figma prototypes

Paste a Figma link to embed an interactive prototype. Versive reads the file and its defined interactions directly from Figma.

<Callout icon="info-circle" color="#71717a">
The Figma file needs link sharing enabled ("Anyone with the link can view") for Versive to import it. Versive shows specific guidance if your file's sharing settings block the import.
</Callout>

For task-based prototype testing with automatic completion detection, use the dedicated [Prototype Task](/studies/question-types#prototype-task) question type instead of a media attachment.

## Per-language variants

If your study runs in [multiple languages](/studies/languages), you can attach different media per language — German participants see the German screenshot while French participants see the French one.
